# 위협 탐지 및 대응 Skill

## 지원 업무 항목

| 원 업무요건 | 예시 질의 | 사용 Tool | 지원 수준 |
|---|---|---|---|
| 공급망·제로데이 탐지 이력 | "최근 제로데이 취약점 관련 탐지 이력과 영향받은 자산을 보여줘" / "공급망 관련 보안 이슈로 탐지된 자산 목록을 보여줘" | `get_endpoint_threat_alerts` | 지원 |

## 표준 응답 절차
1. 이 Tool은 자산 단위(엔드포인트 ID)로 알림을 조회하므로, "전체 환경"에 대한 질의를 받으면 먼저 `it-asset-inventory` Skill의 `get_all_assets`로 대상 자산 목록을 확보한 뒤 필요한 자산에 대해 개별 조회하는 흐름을 사용자에게 안내한다.
2. 특정 자산 ID가 주어지면 바로 `get_endpoint_threat_alerts(endpointId=...)`를 호출한다.
3. 연결 상태가 `READY`가 아니면 잠시 후 재시도하도록 안내한다(Direct Connect 연결은 5분 비활성 시 자동 종료).
4. 알림 발견 시 발생 시각(`start`/`pendingAt`), 유형(`type`), 값(`value`)을 중심으로 요약한다.

## 이 Skill이 다루지 않는 것
- 조직 전체를 한 번에 스캔해 제로데이 탐지 이력을 전수 조사하는 기능(Tool이 엔드포인트 단위 조회만 지원)
- 클라우드 워크로드의 패치 상태(Discover의 클라우드 태그 필드가 항상 비어있어 미지원)

## 주의사항
- `resolve_threat_alert`(알림 해결 처리)는 상태를 되돌릴 수 없는 쓰기 동작이므로, 사용자가 명시적으로 "해결 처리해줘"라고 요청할 때만 사용하고 반드시 대상 GUID를 재확인한다.
